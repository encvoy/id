# Trusted Widget

`trusted-widget` is a compact React component for embedding authentication and account controls in an application.

## Installation

```bash
npm install trusted-widget
```

The host application must provide the peer dependencies listed in `package.json`, including React, React DOM, Material UI, and Emotion.

## Development

```bash
npm install
npm run dev
```

Available build targets:

- `npm run build` builds the default package.
- `npm run build:umd` builds the UMD bundle.
- `npm run build:cjs-esm-types` builds CommonJS, ES modules, and declarations.
- `npm run pack` creates the npm package archive.
